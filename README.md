# חזרה לכימיה ט׳

אפליקציית לימוד ותרגול לקראת המבחן בכימיה של כיתה ט׳: השפה הכימית, היערכות אלקטרונים, קשרים ויכולת קישור, תגובה כימית, אנדותרמי ואקסותרמי.

- 110 שאלות תרגול עם רמזים והסברים, ומבחן דמה עם ציון.
- עובדת גם בלי אינטרנט אחרי הפתיחה הראשונה, ואפשר להוסיף אותה למסך הבית.
- פרטיות: ההתקדמות והשם נשמרים רק בדפדפן של המכשיר. שום מידע לא נשלח לשרת.
